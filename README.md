# VovaGames

Общий каталог небольших браузерных игр.

## Структура

- `index.html` — главная страница каталога;
- `styles.css` — оформление каталога;
- `games/<slug>/` — самостоятельная статическая сборка каждой игры.

Первая игра находится в `games/zvezdny-vova/` и запускается без сборки и серверной части.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер, например:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080/`.

## Добавление игры

1. Создайте новую папку `games/<slug>/`.
2. Поместите в неё `index.html` и ресурсы игры.
3. Добавьте карточку и ссылку на главную страницу.

Проект пригоден для GitHub Pages, Firebase Hosting, Cloudflare Pages и itch.io.
